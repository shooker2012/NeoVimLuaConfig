# Neovim 可观察行为人工验收结果

本目录只保存用户通过启动 Neovim、打开代表性文件并执行编辑器内操作所确认的结果，并纳入版本控制。纯规格、Git 基线、验证脚本、静态断言、内部状态、性能报告和文档任务由自动检查完成，不生成结果文件。

流程：

1. 实施者完成任务实现和适用的自动检查，并判断结果是否能在 Neovim 中直接观察。
2. 仅对可观察行为生成被忽略的 `manual-tests/<任务编号>/TESTING.md` 及测试输入。
3. 用户在 Neovim 中按文档操作，并在对话中反馈通过、失败项和备注。
4. 实施者根据用户反馈生成 `<任务编号>.md`，不得推测或代替用户确认。
5. 可观察行为结果为通过时，才可勾选对应顶层任务；非可观察任务在自动检查通过后直接完成。

可观察行为的依赖未完成时不生成结果。非可观察任务不创建空结果文件。
